One line in the voice of a hardware wallet refusing to sign a transaction at 3 AM — the wallet has its own 3 AM routine, and all three parts of it say no. The program writes one line to `/output/entry.txt`:

> 3 AM is when I back myself up, count my keys, and judge your life choices. All three say no.

## Run it

```sh
python3 main.py
```
